# Architecting Solutions on AWS

This project collects a set of AWS architecture case studies focused on common solution design scenarios. Each case includes a written breakdown of the problem, business requirements, and an accompanying architecture diagram.

## Project Structure

- `case_1.md` - Serverless web backend on AWS
- `case_2.md` - Serverless data analytics on AWS
- `case_3.md` - Hybrid solution for container-based workloads
- `case_4.md` - AWS account governance and management best practices
- `images/` - Diagrams for each case study

## Purpose

The repository is useful for studying AWS architecture patterns, reviewing solution design tradeoffs, and organizing example case responses for learning or interview preparation.

## How to Use

Open any `case_*.md` file to review the scenario, then refer to the matching image in `images/` for the visual architecture.
